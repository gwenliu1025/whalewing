# 知识库 Agent 入口

本目录是员工的个人知识库，由鲸翼插件初始化。在 DSH 中通过鲸翼知识工具读写；用其他 Agent 打开本目录时，同样遵守以下规则。

## 查阅

- 先读 [知识库规则](00-系统/规则/知识库规则.md) 和 [知识库首页](00-系统/知识库首页.md)，按导航定位并读取完成任务所需的原文，不只依据导航摘要作答。
- 多个来源冲突时按知识库规则中的版本规则处理；证据不足时报告冲突，不擅自指定当前版本。
- 回答时说明关键依据文件、资料时效和缺失信息。

## 写入

- 新内容进入十区主结构，不在根级新建其他分类目录；一项内容只保留一个主文件，跨项目、领域和主题的关系用属性、双链和 MOC 表达。
- 根目录本文件、`00-系统/规则`、`00-系统/模板` 和 `00-系统/Bases` 由插件维护，日常不修改；`.whalewing` 是插件内部数据，不读写。
- 未经员工确认，不批量移动、覆盖、重命名或删除；执行已确认的批量操作前仍核对路径、文件数量和目标。

## 安全

- 不读取或写入密码、Token、API Key、私钥、浏览器凭据、客户机密和可识别个人资料。
- `80-外部索引` 中的路径不是自动操作授权；修改库外原件前按当前任务重新确认范围。
