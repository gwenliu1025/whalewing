# 作品模板

自己成果的骨架。放在 `70-作品` 的报告、文章、PPT 等子目录，文件名与 H1 用作品标题；写法见[作品写作规范](../规则/作品写作规范.md)，分类见[知识库规则](../规则/知识库规则.md)。`output_type` 写实际类型，如 report、article、ppt；原件在库外时用 `external_location` 或外部索引指向。

```markdown
---
type: output
output_type: report
status: draft
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
# project: "[[项目 - 名称]]"
# published: YYYY-MM-DD
# external_location: 库外原件位置
---
```
