# 月回顾模板

每月回顾与工作安排的骨架。文件名与 H1 用 `YYYY-MM`，放在 `60-时间线/月记/YYYY`；按[知识库规则](../规则/知识库规则.md)填写，本月认识按实际情况写，不凑条数。

```markdown
---
type: timeline
timeline_type: monthly
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
---

# YYYY-MM

## 本月工作安排

## 月末检查

- [ ] 汇总完成的项目和作品
- [ ] 检查长期领域状态
- [ ] 归档结束的项目
- [ ] 检查外部文件路径和备份
- [ ] 合并重复笔记

## 本月最重要的认识

## 下月准备深入的主题
```
