# 外部文件索引模板

库外原件的登记页。文件名与 H1 用 `资产 - 名称`，放在 `80-外部索引` 的代码项目、工作文件或数字资产子目录；按[知识库规则](../规则/知识库规则.md)只记真实位置、用途、范围和备份，不复制原件，路径也不代表操作授权。

```markdown
---
type: asset-index
asset_type: 工作文件
status: active
location: 库外实际位置
last_checked: YYYY-MM-DD
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
# backup_status: 备份情况
# project: "[[项目 - 名称]]"
---

## 文件位置
```
