# 项目模板

有目标和完成条件的事项。文件名与 H1 用 `项目 - 名称`，放在 `20-项目/工作` 或 `20-项目/学习`；按[知识库规则](../规则/知识库规则.md)记录目标、范围、决定、进度、风险和下一步，不写每日流水。结束后改为 `archived` 并移到 `90-归档/已完成项目`。

---
type: project
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD

# started: YYYY-MM-DD
