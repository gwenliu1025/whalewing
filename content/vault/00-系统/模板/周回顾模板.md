# 周回顾模板

每周回顾的骨架。文件名与 H1 用 `YYYY-Www`，放在 `60-时间线/周记/YYYY`；按[知识库规则](../规则/知识库规则.md)和[知识库使用说明](../规则/知识库使用说明.md)的回顾节奏填写，按实际内容取舍，空栏目可以删去。

```markdown
---
type: timeline
timeline_type: weekly
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
---

# YYYY-Www

## 收件箱

- [ ] 处理超过七天的内容
- [ ] 删除没有明确价值的剪藏

## 项目

- [ ] 检查每个活动项目的下一步
- [ ] 暂停或归档不再推进的项目

## 知识

- [ ] 有值得长期保留的认识时，整理成笔记
- [ ] 更新相关 MOC

## 待确认

## 输出

- [ ] 检查可以发展为文章、PPT 或行动的知识
```
