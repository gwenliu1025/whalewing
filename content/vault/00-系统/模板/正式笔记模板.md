# 正式笔记模板

创建前查找现有主文件，依据[知识库规则](../规则/知识库规则.md)选择类型、状态、目录和命名。模板用于构造新笔记，不作为已有业务事实。各类型有专用骨架时优先取用：

| 对象 | 模板 |
| --- | --- |
| 项目 | [项目模板](项目模板.md) |
| 领域 | [领域模板](领域模板.md) |
| 原子笔记 | [原子笔记模板](原子笔记模板.md) |
| 主题导航 | [MOC模板](MOC模板.md) |
| 书籍来源 | [书籍来源模板](书籍来源模板.md) |
| 网页剪藏 | [网页剪藏模板](网页剪藏模板.md) |
| 作品 | [作品模板](作品模板.md) |
| 外部索引 | [外部文件索引模板](外部文件索引模板.md) |
| 日记、周记、月记 | [日记模板](日记模板.md)、[周回顾模板](周回顾模板.md)、[月回顾模板](月回顾模板.md) |
| 整理日记与任务记录 | [任务日记模板](任务日记模板.md) |

没有专用模板的对象（如课程、会议来源、人生事件）用下面的通用属性：

```yaml
---
type: atomic
status: seedling
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
---
```

正文写清一个独立结论及其依据、适用范围、未确认部分和真实关系链接。来源或项目等属性仅在有对应对象时加入；成熟知识的来源与关系须满足规则。

项目正文按实际需要记录目标、范围、当前结论、风险和下一步；来源笔记保留出处、日期、定位和个人理解；外部索引只保留实际原件位置、用途、范围及必要恢复信息。不存在的字段或对象不生成空壳，事实未确认不写成确定结论。
