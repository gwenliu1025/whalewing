# 知识库首页

这是当前员工的独立知识库。专家与定时整理共享同一内容；文件可以由 Obsidian 阅读和编辑，目录和索引不复制库外原件。导航只用来找文件，具体结论回到原文核对。

## 快速查找

| 要找什么 | 入口 |
| --- | --- |
| 分类、属性、来源、纠偏、覆盖和恢复 | [知识库规则](规则/知识库规则.md)，唯一的维护规则入口 |
| 日常怎么记、怎么回顾 | [知识库使用说明](规则/知识库使用说明.md) |

| 整理日记与深度任务记录 | [任务日记模板](模板/任务日记模板.md)；任务记录放在 `00-系统/索引/任务` |
